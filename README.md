## 搭网盘的 VPS 怎么选：配置和机房都别拍脑袋

网盘场景下，硬盘容量和月流量比 CPU 更值得花钱，内存有 1GB 就够跑主流网盘程序。这是它和建站最大的区别——网站看并发，网盘看存量。

配置优先级可以这样排：

1. **内存**：Nextcloud、Cloudreve 个人使用 1GB 绰绰有余。Cloudreve 更省，单个程序文件就能跑，数据库用自带的 SQLite 即可
2. **硬盘**：按要存的东西算。照片和文档为主，25GB 起步；想放视频在线看，45GB 以上才踏实
3. **月流量**：网盘是“下载型”应用，别人每下一次你分享的文件就消耗对应流量。分享频繁就往大了选
4. **CPU**：解压、生成缩略图时偶尔吃一下，1 到 2 核足够

## 部署实操：从 SSH 登录到打开网盘首页

整个过程可以概括为四步：连上服务器、下载程序、启动、打开网页。Cloudreve 从零到登录页，十分钟以内能搞定。

**1. 连接并更新系统**

拿到 VPS 的 IP 和 root 密码后：

bash
ssh root@你的VPS_IP
apt update && apt upgrade -y
apt install -y unzip wget curl


**2. 下载 Cloudreve**

先去项目的 GitHub Releases 页面看一眼最新版本号，替换下面命令里的版本：

bash
wget https://github.com/cloudreve/Cloudreve/releases/download/3.5.3/cloudreve_3.5.3_linux_amd64.tar.gz
tar -zxvf cloudreve_3.5.3_linux_amd64.tar.gz
chmod +x cloudreve


**3. 启动并登录**

bash
./cloudreve


首次运行会生成配置文件和数据库，并在屏幕上打印初始管理员的账号密码，记得复制保存。浏览器打开 `http://你的VPS_IP:5212`，就能看到网盘登录页了。

**4. 让它常驻后台**

直接跑的话，SSH 一断程序就停。新建 `/etc/systemd/system/cloudreve.service`，写入：


[Unit]
Description=Cloudreve
After=network.target

[Service]
Type=simple
WorkingDirectory=/root
ExecStart=/root/cloudreve
Restart=always

[Install]
WantedBy=multi-user.target


然后执行：

bash
systemctl daemon-reexec
systemctl enable cloudreve
systemctl start cloudreve


这样无论是断开 SSH 还是服务器重启，网盘都会自动拉起来。

**5. 可选：域名加 HTTPS**

确定长期用了，把域名解析到服务器 IP，装 Nginx 反代到 5212 端口，再用 Certbot 一条命令签免费证书：

bash
apt install certbot python3-certbot-nginx -y
certbot --nginx -d pan.yourdomain.com


> 两个容易踩的坑提前说：一是 Nginx 默认上传限制很小，记得在配置里加 `client_max_body_size 2G;`，否则大文件必然上传失败；二是遇到上传报错，先检查 Nginx 配置和系统上传限制，Cloudreve 本身是支持断点续传的。

确实有人连 SSH 都不想碰。这类需求可以选提供应用镜像的商家——比如 Vultr 的 Marketplace 里就有现成的 Nextcloud 镜像，开通时勾选，开机直接是装好的网盘，按月付费（入门档 $2.5/月起）。代价是同样的配置，月付成本远高于年付。折中办法是在 VPS 上装宝塔面板，用图形界面管理站点和证书，再部署网盘程序。

## 常见问题

**1GB 内存的 VPS 跑网盘真的够吗？**

够。Nextcloud 加数据库，单人不做重负载操作没问题；Cloudreve 更省。真正会卡住你的是硬盘容量和月流量，不是内存。

**月流量 1TB 够用吗？**

看分享频率。一个人日常同步照片文档，1TB 大概率用不完；经常把大文件分享出去给别人下载，或者拿来做离线下载，就按 2TB 往上选。流量超了要等下个周期重置，具体超额规则以商家条款为准。

**想要离线下载怎么办？**

Aria2 是标准答案：让服务器替你下载远程文件，高速且不用挂着自己的电脑，配合 AriaNg 面板在网页上操作。装在同一台 VPS 上和网盘搭配用，是最常见的玩法。

**需要备案吗？**

机房在境外就不用备案，这也是大多数人选海外 VPS 搭网盘的原因之一。域名解析、HTTPS 配置都不受影响。

**国内访问速度有保障吗？**

普通国际线路，平时用没问题，晚高峰可能有波动，别拿它对标专门的优化线路。实在在意速度，可以套一层 CDN 缓存部分访问流量。
